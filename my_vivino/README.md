# Welcome to My Vivino
***

## Task
The problem is that My Vivino currently relies on an old rules-based recommendation system, which is limited, hard to improve, and not scalable for a marketplace with millions of users. The challenge is to build a data science solution that can analyze wine data, extract useful patterns, and create a recommendation MVP that improves wine discovery and supports business decisions.

## Description
This project solves the problem by building a content-based wine recommendation MVP using public wine review data. The work follows a complete data science workflow: data collection, cleaning, exploration, visualization, machine learning, and communication of results. The notebook analyzes wine descriptions, prices, countries, varieties, and ratings to identify high-value wines, predict wine variety, and recommend similar wines. The final result is a scientific-style experiment with business impact discussion and a production-oriented MVP approach.

## Installation
Create a virtual environment with `python3 -m venv .venv`, install dependencies with `./.venv/bin/python -m pip install --upgrade "pip<22" setuptools wheel`, then run `./.venv/bin/pip install -r requirements.txt`.

## Usage
Run `python3 bootstrap_my_vivino.py` to generate the project files, then open the notebook with `./.venv/bin/jupyter notebook my_vivino.ipynb`.
